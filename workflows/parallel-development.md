# 并行与同步约定

本项目使用 Git，工作区隔离遵循宿主项目与根 AGENTS.md。不能搬用参考项目的 SVN 分支或 Tomcat 端口管理脚本。

- 同一目录同一功能只由一个活动任务编辑。不同功能并行也须核对共享文件、端口、账号和存储，不能仅因 taskId 不同就视为已隔离。
- 确需并行时使用独立完整工作副本，分别准备引擎、context 和 specs；不以通用 worktree 技能替代 SOP 编排。
- SOP 的本机锁按物理工作区路径隔离；同一任务跨机器续做，先原处 Suspend，同步相同代码及 specs，再由接收处 Resume。
- 不复制本机 Session/Grant/owner 作为写权限；外部 ACTIVE 记录也不授予本地会话权限。
- `.ai-workspace` 与 `specs` 按真实仓库归属分别提交、拉取、合并和推送；保留任务历史和 `.artifacts/`，合并后的内容重新验证。
- 共享数据库、时间偏移和账号的业务测试串行执行；只停止经过身份核实的本任务实例，不全局杀 java 或删除其他任务的锁。
- 跨工作区的任务兼容与恢复按 `.ai-sop/docs/PARALLEL_TASKS.md`；引擎没有跨机器实时锁，尚未同步的冲突不能靠本地 Discover 自动发现。
